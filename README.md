# Instagram Clone

A full-stack Instagram-inspired social media application built with React and Node.js.

## Features

- User registration and login
- Cookie-based authentication
- Create image posts with captions
- View posts in feed
- Like and unlike posts
- Image upload using ImageKit
- Responsive user interface

## Tech Stack

### Frontend

- React
- Vite
- React Router
- Axios
- SCSS
- Remix Icon

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Multer
- ImageKit
